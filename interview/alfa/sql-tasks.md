# SQL: задачи для самопроверки

Данные - [sql-tasks-setup.sql](sql-tasks-setup.sql), любой Postgres 12+. Быстрый способ поднять его дома:

```bash
# из папки interview/alfa; после docker run подождать пару секунд, пока Postgres стартует
docker run -d --rm --name sqlpractice -e POSTGRES_PASSWORD=pg -p 5432:5432 postgres:14-alpine
docker exec -i sqlpractice psql -U postgres < sql-tasks-setup.sql
docker exec -it sqlpractice psql -U postgres
```

Или открыть файл в DBeaver и выполнить целиком. Таблицы:

| Таблица | Колонки | Что внутри |
|---|---|---|
| `departments` | `id`, `name` | 4 отдела |
| `employees` | `id`, `name`, `dept_id`, `manager_id`, `salary` | 12 сотрудников, руководитель - тоже сотрудник |
| `payments` | `id`, `client_id`, `paid_at`, `amount` | 7 платежей, часть загружена дважды |
| `orders` | `id`, `order_date`, `amount` | 7 заказов за конец сентября и начало октября |
| `logins` | `user_id`, `login_date` | входы пользователей по дням |

Порядок работы: сначала ответить без запуска, потом проверить в базе. Ответы и решения прислать текстом -
разберем. Ожидаемые результаты спрятаны под спойлерами.

## Часть 1. Что вернет запрос и почему

Ответить без запуска.

**В1.**

```sql
SELECT COUNT(*), COUNT(dept_id), COUNT(DISTINCT dept_id) FROM employees;
```

**В2.** Автор хотел найти отделы без сотрудников.

```sql
SELECT name FROM departments WHERE id NOT IN (SELECT dept_id FROM employees);
```

**В3.** Автор хотел все отделы и рядом с каждым сотрудников с зарплатой больше 200 000. Сколько отделов
в результате? Как исправить?

```sql
SELECT d.name AS dept, e.name AS employee
FROM departments d
LEFT JOIN employees e ON e.dept_id = d.id
WHERE e.salary > 200000;
```

**В4.**

```sql
SELECT 5 / 2, 5 / 2.0, NULL = NULL, 'a' || NULL,
       (SELECT AVG(x) FROM (VALUES (1), (NULL), (3)) t(x));
```

**В5.** Автор хотел вторую по величине зарплату.

```sql
SELECT name, salary FROM employees ORDER BY salary DESC LIMIT 1 OFFSET 1;
```

## Часть 2. Написать запрос

**З1. Вторая по величине зарплата.** Вывести зарплату и всех, кто ее получает.

**З2. Дубли платежей.** Дубль - одинаковые `client_id`, `paid_at`, `amount`.
- а) Вывести каждую группу дублей и число копий.
- б) Удалить дубли, оставив в каждой группе строку с наименьшим `id`. Проверять внутри `BEGIN ... ROLLBACK`.

**З3. Топ-2 зарплаты в каждом отделе.** Название отдела, имя, зарплата. Равные зарплаты делят одно место:
если две самые высокие зарплаты одинаковы, следующая по величине - второе место.

**З4. Нарастающий итог.** Выручка по дням и нарастающий итог с начала месяца: `order_date`, выручка за день,
итог с начала месяца по этот день включительно.

**З5. Больше, чем у руководителя.** Сотрудники, у которых зарплата выше, чем у их руководителя: имя, зарплата,
имя руководителя, его зарплата.

**З6. Отделы без сотрудников.** Написать правильно (см. В2). Назвать еще один способ.

**З7. Самая длинная серия входов.** Для каждого пользователя - самая длинная серия дней подряд с входами:
первый день, последний день, число дней. Если таких серий несколько - самая ранняя.
