# Яндекс, Техплатформа городских сервисов: подготовка к собеседованию

Вакансия: Backend-разработчик (Python), гибрид Москва/Петербург. HR-скрининг прошел 02.10.2026.
Следующий этап - секция на кодинг Python, понедельник 05.10.2026.

## Формат секции (yandex.ru/jobs/interview/backend, вкладка Python, 02.10.2026)

- 1,5 часа: 1 час на задачу, 30 минут на организационные моменты и обсуждение.
- Своя IDE с демонстрацией экрана, Python 3.10+. Zoom или Телемост, камера включена.
  Встречу могут записывать для расшифровки ИИ.
- Задача прикладная, близкая к реальному проекту. Примеры от Яндекса:
  написать автотесты (обычно pytest); реализовать продуктовую фичу или оптимизировать код;
  исправить продуктовые или технические ошибки в коде.
- Интернет и документацию можно. Copilot, ChatGPT, Cursor, Claude и любые ИИ-подсказки - нельзя.
- Что повторить, по словам Яндекса: стандартные конструкции и паттерны языка, владение памятью,
  базовые знания многопоточности и асинхронности.
- Советы Яндекса: уточнять условие до кода, думать вслух, предлагать варианты и улучшения,
  проверять код перед сдачей. Сначала рабочее решение, потом красивое.

## Что оценивают (по описанию аналогичных секций Java/Kotlin на той же странице)

Владение языком и стандартной библиотекой; интерфейсы классов и функций; выбор структур данных;
понятный рабочий код; покрытие unit-тестами; объяснение хода решения.

## Что пишут кандидаты

- С 2025 года секция называется Advanced Code и идет до алгоритмической. Дают тест - нужно
  реализовать функцию под него, либо дописать модуль, либо написать тесты к готовому коду.
  Порядок: согласовать интерфейс, написать тесты, реализовать, прогнать (habr.com/ru/articles/882030).
- Пример задачи из комментариев: часть текстового редактора - история изменений с undo/redo.
- Бизнесовые сюжеты: банкомат, бронирование такси, фильтрация уведомлений, балансировщик,
  карта сайта с обходом ссылок и распараллеливанием (Go-версия, habr.com/ru/articles/1006022).
- Остальные этапы для senior: алгоритмы (2 задачи easy/medium, онлайн-редактор), архитектура,
  секция про опыт (STAR, проект не старше 2-3 лет), финалы с командами.
  Опыт кандидата из статьи 1006022: senior не дали из-за "недостаточно сложного" проекта на секции опыта.

## Окружение (сделать до понедельника)

- Пустой проект, venv на Python 3.10+, pytest; при желании pytest-asyncio.
- Отключить ИИ в IDE: в PyCharm - Plugins, Local AI/ML Tools - Disable All, сторонние плагины,
  файл `.noai` в корне проекта, Full Line Code Completion выключить. В VS Code - Copilot
  и inline suggestions. Claude Code во время секции закрыть.
- Проверить демонстрацию экрана и камеру в Zoom и Телемосте; крупный шрифт в IDE.
