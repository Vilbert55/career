## Формат секции (yandex.ru/jobs/interview/backend, вкладка Python, 02.10.2026)

- 1,5 часа: 1 час на задачу, 30 минут на организационные моменты и обсуждение.
- Своя IDE с демонстрацией экрана, Python 3.10+. Zoom или Телемост, камера включена.
  Встречу могут записывать для расшифровки ИИ.
- Задача прикладная, близкая к реальному проекту. Примеры от Яндекса:
  написать автотесты (обычно pytest); реализовать продуктовую фичу или оптимизировать код;
  исправить продуктовые или технические ошибки в коде.
- Интернет и документацию можно. Copilot, ChatGPT, Cursor, Claude и любые ИИ-подсказки - нельзя.
- Что повторить, по словам Яндекса: стандартные конструкции и паттерны языка, владение памятью,
  базовые знания многопоточности и асинхронности.
- Советы Яндекса: уточнять условие до кода, думать вслух, предлагать варианты и улучшения,
  проверять код перед сдачей. Сначала рабочее решение, потом красивое.

## Что оценивают (по описанию аналогичных секций Java/Kotlin на той же странице)

Владение языком и стандартной библиотекой; интерфейсы классов и функций; выбор структур данных;
понятный рабочий код; покрытие unit-тестами; объяснение хода решения.

## Как устроен найм с осени 2025 (официально, habr.com/ru/articles/959986, 27.10.2025)

- Единая оценка по профилю и уровню: "Senior Python Developer", а не "разработчик в Такси".
  Секции проводят калиброванные пулы интервьюеров, задачи - из общего пула, не от команды.
  Пройденная оценка дает доступ к вакансиям профиля во всех сервисах.
- Junior и middle проходят 2-3 технические секции, senior - 4-5: кодинг на языке, алгоритмы (АА,
  общая для всех бэкендеров), архитектура, секция про опыт (для техлида). Потом финалы с командами.
- На скрининге задают простые технические вопросы и по ним вместе с ожиданиями по деньгам
  определяют профиль и уровень.

## Окружение (Павел поднимает сам для каждой задачи и перед секцией)

1. Открыть папку проекта в VS Code: `code <папка>`.
2. venv: `python3 -m venv .venv`, `.venv/bin/pip install pytest` (для async - `pytest-asyncio`),
   выбрать интерпретатор `.venv` в VS Code (Python: Select Interpreter).
3. ИИ выключить - `.vscode/settings.json` проекта:

   ```json
   {
       "chat.disableAIFeatures": true,
       "github.copilot.enable": {"*": false},
       "editor.inlineSuggest.enabled": false,
       "python.testing.pytestEnabled": true,
       "editor.fontSize": 16
   }
   ```

   Расширения Copilot в VS Code не установлены (проверено 02.10.2026, VS Code 1.135).
   Claude Code во время секции закрыть.
   Линтер: `pip install ruff` в venv + расширение VS Code `charliermarsh.ruff` (поставлено 02.10.2026),
   в settings.json - `"ruff.importStrategy": "fromEnvironment"`.
4. Проверить, что `pytest` запускается из терминала и из панели Testing.
5. Перед секцией: демонстрация экрана и камера в Zoom и Телемосте, крупный шрифт.
