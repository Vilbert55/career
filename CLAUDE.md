## Правила для резюме

- Про РЖД и КХД писать можно. Объёмы работ и компонентов (число доменов, топиков, задач) — можно.
  **Объёмы данных — нельзя** (терабайты, число таблиц, строк).
- NDA есть: технические подробности не тянуть, уровень — «что сделал и какой результат».
- GitHub (`github.com/Vilbert55`) — только ссылкой, проекты не выставлять.
- Резюме в 2026 году первым читает ИИ-фильтр: нужны ключевые слова из вакансий, стандартные
  названия должностей и навыков, измеримые результаты. При этом резюме должно звучать как Павел:
  сухо, по делу, без громких слов.
- **Резюме на hh скрыто от ООО "Цифровые Сервисы" и ОЦРВ.** РЖД не скрываем (решение Павла, 29.09.2026).
  Старое резюме "Python Developer" скрыто ("Не видно никому"), статус профиля - "Рассматриваю предложения".
- Стиль текстов: русский, утвердительные формулировки без оборота «не X, а Y», прямые кавычки,
  без капслока.
- В тексте резюме только символы с обычной клавиатуры: дефис вместо тире, без стрелок и знака
  рубля (проверка `tools/check_resume.py`). Результаты - верхнеуровнево, без технических
  подробностей. Курсы подаем сухо, без акцента.

## Инструменты и приёмы

- `tools/hh_collect.py` — выборка вакансий hh через публичные страницы (JSON из
  `<template id="HH-Lux-InitialState">`), анонимно, пауза 2–4 с. Павел разрешил небольшие выборки.
- `tools/habr_collect.py` (вакансии, `/api/frontend/vacancies`), `tools/habr_resumes.py` (профили,
  `/api/frontend_v1/resumes`, без аккаунта компании — 10 на запрос; обезличены, в git не кладём),
  `tools/habr_salaries.py` (калькулятор `/api/frontend_v1/salary_calculator/general_graph`,
  параметры `spec_aliases[]`, `skills[]` (Python=446), `locations[]` (c_678 Москва, c_679 СПб)).
- `tools/analyze.py` — сводка, `tools/check_resume.py` — проверка символов в резюме.
- Каноничные названия навыков hh — `api.hh.ru/suggests/skill_set?text=...` (анонимно).
- Браузер (claude-in-chrome): Павел залогинен на hh, Хабр Карьере, LinkedIn. Правки на hh —
  по его запросу. Грабли редактора hh: мастер создания публикует резюме сразу; опыт и курсы —
  общие записи профиля, к резюме привязываются галочками; город и языки — в профиле;
  фоновые вкладки тормозят таймеры JS и теряют или искажают ввод с клавиатуры (просить Павла вывести вкладку вперед); скриншоты иногда в полмасштаба — работать через ref;
  значение, подставленное в textarea скриптом, форма не сохраняет — выделять фрагмент скриптом
  (setSelectionRange) и удалять или печатать клавишами, после сохранения сверять страницу резюме.
