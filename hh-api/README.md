# Доступ к данным hh.ru: что проверено

Проверено 29.09.2026 по dev.hh.ru, документации `github.com/hhru/api` (копия в `docs/`)
и живыми запросами.

## API для соискателей закрыт

- В форме регистрации приложения на dev.hh.ru прямо написано: "поддержка API для соискателей
  прекращена 15 декабря 2025". В поле "Приложением будут пользоваться" остались два варианта:
  сотрудники одного работодателя или нескольких работодателей.
- Поиск вакансий (`GET /vacancies`), просмотр вакансии и компании доступны с токеном приложения
  (`client_credentials`) или работодателя. В OpenAPI у `/vacancies` остался тег "Поиск вакансий
  для соискателя", но токен соискателя тоже выдаётся только через зарегистрированное приложение.
- Логин и пароль соискателя в API не используются: только OAuth через приложение. Условия API
  (п. 3.6) запрещают приложениям собирать логины и пароли.
- Поиск и просмотр резюме, банк зарплат (`/salary_statistics`) — только для работодателя
  с платным доступом.
- Итог: зарегистрировать приложение для личного поиска работы честным описанием почти наверняка
  не выйдет, форма рассчитана на работодателей. Условия при этом разрешают личное использование
  (п. 3.8) и сбор "информации о рынке труда" (п. 3.3) — но только через одобренное приложение.

## Что отвечает без токена

| Запрос | Ответ |
|---|---|
| `/vacancies`, `/vacancies/{id}`, `/employers/{id}` | 403 forbidden |
| `/dictionaries`, `/professional_roles`, `/areas` | 200 |
| `/suggests/vacancy_search_keyword` | 200 |

## Сайт hh.ru

- Поиск вакансий на сайте работает в браузере без ограничений.
- Поиск резюме соискателю доступен урезанно: текст запроса игнорируется, показывается общая
  лента ("остальные можно увидеть после регистрации работодателя"). Резюме конкурентов по
  ключевым словам через hh не посмотреть.
- Соглашение соискателя (`hh.ru/account/agreement`) запрещает "плагины, осуществляющие
  автоматический сбор и анализ данных (парсинг)" и "программные средства, имитирующие работу
  Соискателя". Риск — блокировка аккаунта Павла.

## Другие источники

- **trudvsem.ru** (портал "Работа России") — открытый API без ключа:
  `http://opendata.trudvsem.ru/api/v1/vacancies`, отвечает 200. IT-вакансий меньше, много госсектора.
- **Хабр Карьера** (`career.habr.com`) — публичные вакансии и открытые профили специалистов,
  зарплатный калькулятор. Страницы отвечают 200; условия использования проверить перед сбором.
